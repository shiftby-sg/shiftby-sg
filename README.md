# ShiftBy Website

This repository contains the governed implementation scaffold for the ShiftBy website.

## Current phase

WP-A establishes the repository-facing contract for the frozen ShiftBy V2 website.
The implementation path is retained Next.js with Codex modification.

The contract records:

- eight primary IA roles and eleven minimum implementation pages;
- primary, child-detail, utility, and legacy-redirect route classes;
- the three canonical capabilities;
- the typed Insight route family boundary;
- V1 route dispositions and carried WS4 remediation controls.

Page composition, production copy, visual implementation, redirects, forms, and
publishing behavior remain owned by later workpackages.
