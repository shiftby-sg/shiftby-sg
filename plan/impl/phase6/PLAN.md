# Phase 6 - Validation

Purpose: Validate all requirements.

Expected outcome: Release candidate.

Mode: `bounded execution`

Must validate:

- doctrine fidelity
- narrative fidelity
- design parity
- responsive behavior
- accessibility
- SEO
- sitemap
- robots
- llms.txt
- structured data
- performance
- Core Web Vitals

Must produce evidence.
Must not self-approve release readiness.

Evidence expectation for future runs:

- `workpacket_root`
- `phase_id`
- `run_id`
- `tested_condition`
- `expected_outcome`
- `actual_outcome`
- `passes`
- `blockers`
- `created_at` or `generated_at` where available
